# 🚀 AI Interview Simulator

Practice like it’s a real interview. Improve like a pro.

AI Interview Simulator is a full-stack web application designed to help students and developers prepare for technical interviews through realistic, role-based mock sessions and instant AI feedback.

Instead of just solving problems, this tool helps you think, explain, and perform under real interview conditions — exactly what recruiters look for.

---

## 🎯 Why This Project?

Most candidates struggle in interviews not because they lack knowledge, but because they:
- Cannot explain concepts clearly
- Panic under pressure
- Lack structured thinking

This platform helps you:
- Practice anytime
- Simulate real interview scenarios
- Improve communication and technical clarity
- Build confidence before actual interviews

---

## ✨ Features

- AI-generated technical and behavioral questions
- Role-based interviews:
  - Frontend
  - Backend
  - Full Stack
  - Software Engineer (SDE)
- Instant answer evaluation with improvement suggestions
- Difficulty levels (Beginner / Intermediate / Advanced)
- Real-time text-based interview interaction
- Clean and modern UI

## ⚙️ How It Works

1. Select your target role
2. AI generates interview questions
3. Submit your answer
4. AI evaluates:
   - Technical accuracy
   - Depth of knowledge
   - Clarity of explanation
5. Receive feedback and suggestions to improve

## 🚀 Getting Started

### Clone the repository

git clone https://github.com/YOUR-USERNAME/AI-Interview-Simulator.git  
cd AI-Interview-Simulator

---

### Backend Setup

cd server  
npm install  

Create a .env file and add:

API_KEY=your_ai_api_key  

Run backend:

npm start

---

### Frontend Setup

cd client  
npm install  
npm run dev
